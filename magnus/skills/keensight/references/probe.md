# 摸底：钉下有向图的根

**目的**：测出用户在目标脉络上的**真实起点**——已掌握 / 欠缺的前置——把有向图的根钉在恰当那一层。起点定低了浪费篇幅，定高了断链。

**硬性要求：必须问满 3 轮 × 12 题 = 36 题。** 用客户端**原生问卷**逐轮问，顺序恒为粗 → 细。**不得自行削减轮次或题量**——哪怕你觉得已经摸清了，也要问满；摸底不足导致起点错判，是返工最贵的失败。用户可以选择不答某些题，但**你必须把 36 题都摆出来**。

**zero-shot 默认**：仅对用户**显式跳过**的题，按**大二本科**水平兜底（按目标学科取对应专业的大二学生：数学 / 物理 / 计算 / 文史哲皆然）；不能拿「默认值」替代提问。

## 三轮 × 每轮 12 题，从粗到细

- **轮一（粗，12 题）**——学科板块归属、最高相关训练、接触过的标志性课程 / 工具 / 语言，快速定位象限。
- **轮二（中，12 题）**——目标脉络的几大支柱，逐柱自评掌握度，找出主干上的断档层。
- **轮三（细，12 题）**——贴着「前沿终点」反向点名具体前置概念，逐个核到底，精确定位根节点。

## 出题方法论

- **题目按目标主题现场生成**，不套固定题库（主题差异太大）；但**题量恒为每轮 12**。
- **从前沿终点反向列前置**：终点需要什么 → 那又需要什么 …… 逐层下探；哪一层用户开始断档，根就钉在那一层之上。
- 每题给**自评档位**而非是非，典型四档：没学过 / 听过没学过 / 学过会用 / 能教别人——档位差直接映射成有向图里要不要展开该节点。
- **不问英文水平**（假定用户英文不错）。

**产出**：一份「起点 spec」——读者已具备 vs 待补的前置清单，作为铺脉（[`authoring.md`](authoring.md)）的根。
