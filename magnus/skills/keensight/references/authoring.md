# 铺脉与撰写

## 铺脉：知识是一张有向图

- **节点** = 一个原语 / 定义 / 结论；**边** = 依赖。先定原语，后用其符号。
- 成文按**拓扑序**：任何符号 / 概念在被用到前必已定义，**无前向悬空引用**。
- **深度优先**：只保留「起点 → 前沿」最重要的主干脉络。对它的批评、对其简化假设之局限的讨论、对可观测原语的批判，**忽略或一笔带过**（`remark`），不开支线。
- **前沿终点是图的汇点**：把「到达前沿」锚成一个**可检验判据**——能读懂某篇标志性论文 / 能复现某个关键结果——作为有向图的 sink 与收敛点，避免「挖到哪算到了」。
- **半动态**：拓扑定型即开写，但**写作中暴露未预见的前置依赖时，允许局部插入节点、局部重排**（教学中常发现「要讲 A 必先补 B」）；**主干顺序仍冻结**，插点后回查拓扑序仍无前向悬空引用。
- **篇幅护栏**：铺脉后**预估图深度与叶子原语数**，给规模一个事前估值；某条链异常深时**告警**（多半是跑偏或该下沉附录），但**不为控篇幅牺牲严谨度**——篇幅 = 图的深度，每条边都严谨架桥，**绝不**科普式跳跃省节点。

## 知三陈一 · 反幻觉

- 呈现「一」的宽度，自己必须掌握「三」的宽度——多出的两倍**隐而不说**，只用于保证选取的主干正确、表述无误。
- **用 sub-agent 扩宽度、收主干**：起 parallel sub-agent 调研每个节点周边，让它们只回传蒸馏后的主干，把宽度留在 sub-agent 的 context，别灌进你自己的主 context。
- **不凭印象**：每条陈述都调工具核查、再三阅读原始材料。缺料就向用户**提需**（OCR 推荐 minerU；用户最终说了算）。
- **高风险局部触发查实**：前沿章节的**关键定理 / 数据 / 引用**必须走「查实」子流程——找到原始来源逐条核对、数值必要时跑代码验算——再落笔。越靠近前沿、训练数据越稀疏处，查实越是「绝不科普」的硬防线；实在无法核查的论断，**显式降级标注**，不蒙混。

## 撰写：规格 / 推演双轨

每个节点（章 / 节）逐节双轨、整体线性：

- **规格（`spec`）**——精确、形式化地讲「是什么」：定义、定理陈述、接口 / 签名。读者只沿规格轨纵览，即得指挥 AI 所需的一切。
- **推演（`deriv`）**——完整严谨地讲「为什么 / 怎么来」：证明、推导、实现。起疑或好奇时下潜。
- **承重节点高亮**：主干上最吃重的一步用 `keystep`（链条节点）框出；真正的「灵魂一步」用 `soul` 框出，让读者一眼看到脉络的关节。
- **重机械下沉附录**——与主干推进无关、但完备性要求收录的繁重证明 / 长表放 appendix。

**spec 不是科普**：科普把「是什么」和「为什么」一起含糊掉；规格把「是什么」讲到形式化精确，只把「为什么」延后。**严谨度跨层恒定**——越往下只是推演越全，不是越往下才越对。

## 相容的教学法（纯阐述，不引入练习 / 测验）

只用与「深度优先纯阐述」相容的手段提升可学性：

- **predict-before-peek**：抛出关键推导前，先用一句话让读者预判结论或方向，再揭晓。
- **dual-coding**：硬推导之前先给一段**直觉图景**（物理图像 / 几何 / 类比），再进形式化——直觉与形式互为编码。
- **cross-reference 回指**：用 `\cref` 把当前原语回指到它依赖 / 推广的前序原语（「这正是 \cref{...} 那个引理的推广」），让有向图的边在读者眼里显形。

## 全局一致 · 形式化 · 导航 · 可公开

- **全局术语表（notation registry）**：维护一份贯穿全书的记号 / 术语登记表，确保同一符号不被两处重定义、同一概念不两处异名（交付前的跨节点扫描见 [`review-loop.md`](review-loop.md)）。
- **数学与形式化优先**：能用形式化符号精确表达的，不用自然语言含糊。
- **马尔科夫性**：改了主意只留最终态 Y，像 X 从未出现，不写「本来想 X，其实 Y 更好」。
- **语言**：流利干净中文，**禁中英混杂**的 bad pattern；著名术语 / 结论 / 定理 / 现象直接用英文（如 Banach space、Noether's theorem）。
- **导航**：卷首放一张「前置 → 主干 → 前沿」的**依赖图**纵览脉络；正文靠分层 PDF 书签 + 原语间 `\cref` 交叉引用，把分层从写作意图落成读者可操作的导航。
- **公开可接受**：完备自包含，不依赖外部私有语境；扉页校徽 + 「北京大学物理学院 · Rise-AGI」署名（见 [`../templates/`](../templates/)）。
