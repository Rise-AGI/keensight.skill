# 铺脉与撰写

## 铺脉：知识是一张有向图

- **节点** = 一个原语 / 定义 / 结论；**边** = 依赖。先定原语，后用其符号。
- 成文按**拓扑序**：任何符号 / 概念在被用到前必已定义，**无前向悬空引用**。
- **深度优先**：只保留「起点 → 前沿」最重要的主干脉络。对它的批评、对其简化假设之局限的讨论、对可观测原语的批判，**忽略或一笔带过**（`remark`），不开支线。
- **篇幅 = 图的深度**：起点到前沿差几跳就写几节点，每条边都严谨架桥。**绝不**用科普式跳跃省掉节点。

## 知三陈一

- 呈现「一」的宽度，自己必须掌握「三」的宽度——多出的两倍**隐而不说**，只用于保证选取的主干正确、表述无误。
- **用 sub-agent 扩宽度、收主干**：起 parallel sub-agent 调研每个节点周边，让它们只回传蒸馏后的主干，把宽度留在 sub-agent 的 context，别灌进你自己的主 context。
- **不凭印象**：每条陈述都调工具核查、再三阅读原始材料。缺料就向用户**提需**（OCR 推荐 minerU；用户最终说了算）。

## 撰写：规格 / 推演双轨

每个节点（章 / 节）逐节双轨、整体线性：

- **规格（`spec`）**——精确、形式化地讲「是什么」：定义、定理陈述、接口 / 签名。读者只沿规格轨纵览，即得指挥 AI 所需的一切。
- **推演（`deriv`）**——完整严谨地讲「为什么 / 怎么来」：证明、推导、实现。起疑或好奇时下潜。
- **重机械下沉附录**——与主干推进无关、但完备性要求收录的繁重证明 / 长表放 appendix。

**spec 不是科普**：科普把「是什么」和「为什么」一起含糊掉；规格把「是什么」讲到形式化精确，只把「为什么」延后。**严谨度跨层恒定**——越往下只是推演越全，不是越往下才越对。

## 形式化优先 · 干净 · 可公开

- **数学与形式化优先**：能用形式化符号精确表达的，不用自然语言含糊。
- **马尔科夫性**：改了主意只留最终态 Y，像 X 从未出现，不写「本来想 X，其实 Y 更好」。
- **语言**：流利干净中文，**禁中英混杂**的 bad pattern；著名术语 / 结论 / 定理 / 现象直接用英文（如 Banach space、Noether's theorem）。
- **公开可接受**：完备自包含，不依赖外部私有语境；扉页校徽 + 「北京大学物理学院 · Rise-AGI」署名（见 [`../templates/`](../templates/)）。
