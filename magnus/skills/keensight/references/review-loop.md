# 交付前评审闸

锋识交付的门槛**与 git push 同闸**：**3 个并行 fresh sub-agent / 连续 2 轮全绿才交付**。

- **轮内冻结草稿**：3 个 agent 评同一份 PDF / 源。
- **轮间冻结 prompt**：每轮起 fresh agent、给完全相同的 prompt（防时变暗示性，以得真改进）。
- 任一 agent 标出实质问题 → 先修问题、计数清零、重新连续两轮。
- 连续两轮全绿 → 交付。

## 契约化核查清单（逐条核，非整体气质判断）

把「教学严谨」沉淀成可逐条核验的契约；每条要么通过、要么给出**具体定位 + 修法**：

1. **有向图完整**——每个记号 / 概念**首次出现处有定义**，无前向悬空引用，起点到前沿主干不断链。
2. **每条边严谨架桥**——无科普式跳跃，无「显然 / 易证」搪塞掉实质步骤。
3. **双轨齐备**——每节点规格 / 推演分明；**只读规格轨即自洽可懂**；顶层规格与底层推演互洽（能互相指挥，不各说各话）。
4. **深度优先**——未跑偏到批评 / 局限 / 可观测原语批判等支线。
5. **前沿终点达成**——卷首声明的「按域到达判据」（读懂论文 / 复现结果，或读懂原典 / 进入争论并自持立场，或项目书自洽可实现）在正文确实被铺到。
6. **论断有据（分两域）**——已知地基的关键定理 / 数据 / 引用经查实（原始来源核对 / 数值验算），无法核查者**已显式降级标注**；越过人类边界的**未来知识**则不查实、不标存疑，但须从已核查地基严格推演、内部自洽、可逐步溯回地基。
7. **记号全局一致**——同一符号无两处重定义，同一概念无两处异名（对照 notation registry 扫一遍）。
8. **语言干净**——流利中文、无中英混杂；著名术语用英文。
9. **公开可接受**——完备自包含、署名齐、PDF 高可读（书签 / 卷首依赖图 / 交叉引用就位）、可直接公开。

## 编译型交付（LaTeX→PDF）的并发纪律

锋识产物经 `latexmk -xelatex` 编译。评审 sub-agent 与主控同在一个构建目录时，**多个 latexmk / xelatex 并发会争抢 `main.aux` / `.fdb_latexmk` / `.fls`**，互相污染、表现为「卡死」，并被误诊成「源里有死循环」（实测曾把单个评审 agent 拖到 87 分钟）。纪律：

- **评审 prompt 明令「禁止 sub-agent 自行运行 latexmk / xelatex」**——它们只读 `.tex` 源审内容，要看排版就读主控已生成的 `main.pdf`。
- **编译正确性由主控一次「隔离编译」裁决**：先 `taskkill` 残留进程、`latexmk -C` 清场、再 `timeout 300 latexmk ...`（用 `timeout` 区分「慢」与「真死循环」：返回 124 即 hang）。一次只跑一个编译实例。
- 主控自己的增量编译（带旧 `.aux`）会**掩盖** fresh-build 才暴露的问题——交付前务必做一次 `-C` 后的 fresh 隔离编译。

## 推荐评审 prompt（轮间冻结此文）

> 通读这份锋识（PDF + 源），按契约清单逐条核：每个记号首现处是否有定义、有无前向悬空引用、每条边是否严谨架桥无科普跳跃、规格轨能否独立读懂且与底层互洽、是否深度优先未跑偏、卷首的按域到达判据是否真被铺到、已知地基的关键论断是否经查实或已显式标注存疑、越界的未来知识是否从地基严格推演且自洽可溯、记号是否全局一致、中文是否干净无中英混杂、是否完备自包含可公开。每挑出一条实质问题都要给出具体定位与修法；全部通过才说「全绿」。不要为了应付而放水，不要让熵增加。（**编译型交付：prompt 内须加「禁止自行运行 latexmk/xelatex」，见上节并发纪律。**）
